# 근육지도 앱 소스

근육지도 사이트 배포 버전 21의 소스입니다.
원본 커밋: b3d33063e467eda0a9c465628eed5935fd761c94

## 컴퓨터에서 실행

1. ZIP을 풀고 `muscle-atlas` 폴더로 이동합니다.
2. Node.js 22 이상과 npm이 설치된 환경에서 `npm ci`를 실행합니다.
3. 소스를 보면서 작업하려면 `npx vite`를 실행하고 터미널에 표시되는 주소를 엽니다.
4. 실제 배포용 파일을 만들려면 `npm run build`를 실행합니다. 결과물은 `dist/`에 생성됩니다.
5. 배포용 빌드를 로컬에서 확인하려면 `npx vite preview`를 실행합니다.

홈 화면 설치와 오프라인 실행을 확인하려면 빌드한 `dist/`를 사이트의 루트 경로에 HTTPS로 제공하세요. 로컬 테스트는 `localhost`에서 할 수 있습니다.

## 구성

- `src/` — 화면, 운동·근육 도감, 기록·백업 기능, 해부 그림과 자세 이미지
- `public/` — 앱 설치 설정(manifest), 아이콘, 앱 복구 페이지
- `make-sw.mjs` — 빌드할 때 오프라인 서비스 워커 생성
- `package.json`, `package-lock.json` — 의존성과 실행 명령
- `src/anatomy-credits.json` — 해부 그림의 출처·라이선스 정보

개인의 운동 기록은 기존 앱에서 **설정 → 기록 백업 · 복원 → 백업 파일 저장**으로 별도 보관합니다. 다른 주소에 배포한 앱으로 자료를 옮길 때는 새 앱의 같은 메뉴에서 해당 파일을 열어 복원합니다.

VPS·n8n에 서버 백업을 저장하려면 자신의 웹훅과 저장소를 연결해야 합니다. 웹훅 연결 규격은 앱의 **기록 백업 · 복원** 메뉴에서 볼 수 있습니다.
